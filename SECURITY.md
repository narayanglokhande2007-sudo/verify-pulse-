# Security Policy

VerifyPulse welcomes good-faith reports about security weaknesses in the public website, published source code, and supported API routes. Responsible disclosure helps us improve the project without placing users at risk.

> **This is an independent project.** VerifyPulse does not currently offer a bug bounty, a paid security-review programme, a guaranteed response time, or a security certification.

## Report a vulnerability privately

Please **do not** open a public GitHub issue for a suspected vulnerability. Send a concise report to [narayanglokhande2007@gmail.com](mailto:narayanglokhande2007@gmail.com) instead.

The report should include the affected URL, route, or repository path; a short reproduction method; the potential impact; and a safe contact method. Screenshots or minimal proof-of-concept details are useful only when they do not expose users or systems to additional harm.

## Keep reports safe

Do not include passwords, OTPs, PINs, API keys, access tokens, bank details, card details, Aadhaar/PAN values, personal information, user scan inputs, or customer data in an initial report. Do not submit live scam links, malware, or harmful files unless a safe method of handling them has first been agreed.

Please avoid actions that could affect real users or infrastructure. This includes denial-of-service testing, mass automated scanning, social engineering, attempts to access accounts or data without permission, and any action that changes or deletes data.

## What happens next

Reports are reviewed on a best-effort basis. VerifyPulse may ask for clarification, assess the issue, make a fix where appropriate, and publish a limited acknowledgement when safe to do so. No timeline, confidentiality agreement, reward, or public acknowledgement is guaranteed.

For current public boundaries and service information, see the [Trust Center](https://www.verify-pulse.com/trust.html), [Service Status](https://www.verify-pulse.com/status.html), and the published [security.txt](https://www.verify-pulse.com/.well-known/security.txt).

## Scope reminder

This policy covers responsible reporting for VerifyPulse-managed public assets. It does not authorize testing of third-party services, AI providers, banks, payment networks, or other external systems that may be mentioned or used by the project.
